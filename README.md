# سوبر ماركت بن سليمان — النظام المحاسبي المتكامل

تم استكمال المشروع فوق التصميم الأساسي الموجود بدل إعادة تصميمه.

## ما تم استكماله

- لوحة التحكم والإحصائيات.
- نقطة بيع POS مع سلة، عميل، فرع، طرق دفع، خصم وضريبة.
- تحديث المخزون تلقائيًا عند البيع والشراء والمرتجعات.
- المنتجات والأقسام: إضافة / تعديل / حذف.
- المشتريات والموردون.
- المبيعات والفواتير.
- المرتجعات وربطها بالفاتورة.
- العملاء.
- الطلبات والتوصيل وتتبع المندوب.
- الفروع.
- الموظفون والمستخدمون والأدوار.
- صفحة تعديل صلاحيات الأدوار.
- المصروفات.
- التقارير.
- المحاسبة ودفتر الحركات والربح الإجمالي والصافي.
- سجل العمليات Audit Log.
- الإعدادات.
- حماية الصفحات حسب الدور.
- دعم كامل للعربية RTL ومتجاوب مع الهاتف.
- LocalStorage كقاعدة تشغيل أولية، مع إبقاء البنية جاهزة للانتقال إلى Firebase/Firestore لاحقًا.

## بيانات الدخول التجريبية

المدير العام:

- اسم المستخدم: `admin`
- كلمة المرور: `123456`

يوجد كذلك مستخدمون تجريبيون في `data.js` لأدوار مدير الفرع والمحاسب والمخزن والكاشير والمندوب.

## ملاحظة Firebase

ملف إعداد Firebase الحالي يحتوي على حقول فارغة عمدًا. النظام يعمل محليًا بدون Firebase في هذه النسخة حتى يتم إدخال إعدادات مشروع Firebase الحقيقية وربط Firestore/Auth لاحقًا.

## الحفاظ على التصميم

تم الإبقاء على ملفات الهوية الأساسية:

- `css/style.css`
- `css/dashboard.css`
- `css/pos.css`
- `css/responsive.css`

وأضيف `css/modules.css` كطبقة إضافية للصفحات الجديدة، بدون إعادة بناء الهوية الأساسية.
